📅 당직 일정 생성기

누적 총 횟수 균형(평일·주말 구분 없이 일직·숙직 각 1회) 후, 원하는 날에 수동 인원(예: 신용범)을 끼워넣거나 일직·숙직을 따로 바꾸면 자동 재계산

1. 기간 · 공휴일 · 수동 인원

신정·3.1절·어린이날·현충일·광복절·개천절·한글날·성탄절은 자동 인식. 음력/대체공휴일은 직접 추가하세요. · 수동 배정 인원은 자동 배정에서 제외되고, 생성 후 일정표에서 원하는 날에 직접 넣습니다.

2. 당직자 (자동 배정)

이름불가일 (예: 3, 5, 10-12)이월(누적차)
이월 = 지난 달까지 누적 총 횟수 − 가장 적게 선 사람의 누적. 자동 계산이 켜져 있으면 일정 생성 때 저장된 기록으로 다시 채웁니다(직접 고치려면 체크 해제).
📥 구글 시트에서 불러오기 (선택)
컬럼 순서: 이름 ⟶ 불가일 ⟶ 이월 (이월값 생략 가능). 위 명단을 덮어씁니다.
